# AI Timeline production defaults

## Director Mode social videos

- For X/social Director Mode cuts, default to a 1080×1080 square master unless the user requests another format.
- Do not use the generic “N additions on one timeline” outro. End on the final featured release card unless the user explicitly asks for a different closing card.
- Treat phone readability as a hard requirement. At 1080×1080, use supporting text around 30–38 px and featured release names around 70 px; do not rely on desktop-scale metadata text.
- Hide Director controls, safe guides, and setup UI from the exported cut.
- Review the intro and every featured release frame at output resolution before the final export or upload.
- Preserve these defaults for future video requests unless the user overrides them.
